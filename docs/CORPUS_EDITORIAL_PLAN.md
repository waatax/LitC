# LitC 全文庫校勘與品質完成計畫

## 完成的定義

每一段必須同時通過三層審核：

1. **古文原文**：章名、段落、文字與標點已對照至少一個第一級來源；遇異文時另以第二來源複核，並記錄採用版本。
2. **白話文**：逐句對應原文，人物、主詞、否定、數量、地名、官名與關鍵術語無誤；不得以機械替換或照抄原文冒充翻譯。
3. **解析**：必須具體對應該段內容，至少說明語境／主旨、關鍵詞義及章法或思想意義；不得套用跨段通用模板。

「欄位非空」不等於完成。只有來源、內容與自動品質閘門全部通過，該段才標記為已校勘。

每段的人工校勘狀態另存於 `src/data/editorialReviews.json`。原文、白話、解析三項必須分別標記為 `verified`，並附至少兩個實際用於比對的來源；單純寫入來源網址不會讓段落通過。

## 來源分級

- **第一級（定本／學術原典）**：中央研究院漢籍電子文獻、國家圖書館善本影像、權威整理本或大學／研究機構發布的校勘本。
- **第二級（可靠交叉核對）**：中國哲學書電子化計劃、Kanripo 漢籍リポジトリ、Wikisource 的有版本說明文本、可靠出版社公開試讀。
- **第三級（僅供白話與教學參考）**：大學課程、教育機構、出版社與具編校資訊的古文學習網站。
- 搜尋彙整站、無作者翻譯與 AI 生成頁面不得作為原文定本；若引用其解釋，必須由更高級來源驗證。

## 異文規則

- 不把不同版本靜默混合；每部書先選定底本。
- 通假字、古今字與異體字原則上保留底本，必要時在解析說明。
- 影響語義的異文須列出「底本文字／他本文字／採用理由」。純標點差異可依現代閱讀需要統一，但不得改變句義。
- 缺字、罕見字及 Unicode 異體必須以影像或第二學術來源複核。

## 執行批次

1. **基準與品質閘門**：產生 50 部、661 篇、3,950 段風險清單；修復失效稽核；建立來源與校勘紀錄格式。
2. **核心經典**：《論語》《孟子》《大學》《中庸》《道德經》《莊子》《孫子兵法》及五經選段。
3. **先秦諸子**：墨、法、兵、雜、道家其餘典籍。
4. **史傳與政論**：史書、奏議、論說與相關選文。
5. **《古文觀止》與文學類**：依篇逐一對照作者別集或權威總集，不以選本轉抄作唯一依據。
6. **全庫複核**：逐段來源覆蓋、異常掃描、重複模板檢查、型別檢查、正式建置與網站抽樣。

## 每批工作流程

1. 鎖定底本與至少一個交叉來源。
2. 比對章名、原文、分段與標點，先修原文。
3. 逐句審白話，記錄關鍵詞與歧義處理。
4. 依實際文本重寫解析。
5. 執行 `node scripts/audit_corpus_quality.js` 與全庫完整性檢查。
6. 僅提交該批相關檔案；建置通過後部署。

## 品質閘門

- 原文、白話或解析不得缺漏或含亂碼／替代字元。
- 每段必須有可追溯來源；高風險異文至少兩源。
- 機械翻譯特徵為零。
- 完全重複解析為零；跨段模板解析為零。
- 章節／段落 ID 必須連續且與資料索引一致。
- TypeScript 型別檢查與正式建置必須通過。
